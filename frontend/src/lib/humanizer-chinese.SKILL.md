# 中文 Humanizer:去除 AI 味,让文字像人写的

> **核心原则:改的是节奏和信息密度,不是词汇。**
> AI 检测器盯的是困惑度(perplexity)和突发性(burstiness)的分布模式,
> 不是"然而"还是"不过"。逐词替换降不了检测分,节奏重组才能。

## 通用要点(先读这个)

1. **句长要有起伏。** 人类写作的句长分布是锯齿状:三字句、40字长句、
   十字句无规律交替。AI 的分布像正态曲线,中庸句占比过高。改写时主动
   制造长短差:连续两三个中长句后,插一个三五字的短句;或把长句掰开。
2. **信息密度要不均匀。** 人写东西详略随心情:核心论点墨迹三段,过渡
   一笔带过,偶尔跑题。AI 每句都均匀发力,像切好的吐司。刻意保留
   "不平衡":有的地方堆细节,有的地方一句话跳过。
3. **敢留毛边。** 口语、插入语、自问自答、话说一半改口("或者说——不,
   这么说吧")、不完美的表达。AI 的"完美感"本身是指纹。但注意:毛边
   要像真人不小心,不能演,刻意插入"哈哈""说实话"反而更假。
4. **结构去模板化。** AI 爱总分总、爱"首先/其次/最后"、爱每段开头
   总结上一段。打乱:让段落长短不一,过渡句可有可无,结尾不必升华。
5. **改写而非替换。** 最有效的操作是拆并重组:两个短句合成一个带
   插入语的长句;长句掰成碎句;整段换个进入角度。同义词替换(然而→不过)
   基本无效,检测器不看这个。

## 一、内容层面的模式

### §1 宏大开场 / 情感绑架开场
- **症状**: "在这个日新月异的时代""在当今社会""不禁让人思考"
- **病根**: 空泛、零信息量、人人都能写
- **修法**: 砍掉,直接从具体事实/场景/问题切入。第一句必须带具体信息。

### §2 升华结尾 / 意义拔高
- **症状**: "让我们共同期待""未来可期""充满了无限可能"
- **病根**: 训练数据里演讲稿和作文的结尾惯性
- **修法**: 结尾停在事实或具体动作上,删掉最后一层包装。或用反问、
  具体的未解问题收尾(不是修辞性反问)。

### §3 空洞总结段
- **症状**: "总之""综上所述",复述前文却不推进任何信息
- **病根**: RLHF 训练出的"必须总结"倾向
- **修法**: 删除。如果删了感觉少点什么,说明前文没写清楚,去补实质。

### §4 宣传腔 / PPT 腔
- **症状**: "赋能""抓手""闭环""颗粒度""组合拳""打通最后一公里"
- **病根**: 训练语料里的商业文案和互联网黑话
- **修法**: 每个黑话翻译成人话。"赋能"→"帮着做到"或直接删。
  领域术语(如法律、医学)保留,行话删除。

### §5 模糊归因
- **症状**: "研究表明""有专家认为""众所周知""普遍认为"
- **病根**: AI 不会真引用,只学到引用的形状
- **修法**: 要么给出具体来源(谁、哪年、哪个研究),要么改成"我注意到"
  "有种说法是"这类诚实表述,要么直接陈述观点不装引用。

### §6 万能例子 / 虚构案例
- **症状**: "比如小明""某公司""张先生"(无具体细节)
- **病根**: 模型生成的占位符例子
- **修法**: 换成具体例子(带名字、数字、时间),或删掉例子直接说事。

### §7 均匀推进,无详略
- **症状**: 每个要点篇幅相等,面面俱到,重点不突出
- **病根**: 指令遵循训练让 AI 倾向"公平对待每个点"
- **修法**: 砍到只剩两三个重点,每个重点用不同篇幅处理:一个展开讲,
  其余一笔带过。

### §8 观点骑墙 / 和稀泥
- **症状**: "各有道理""需要平衡""不能一概而论"
- **病根**: RLHF 的安全训练,避免站队
- **修法**: 逼自己选边,或明确说出两边的核心分歧点在哪,而不是"都有道理"。
  真实的观点文是有立场的。

### §9 强行积极 / 强行升华
- **症状**: 失败案例也要"宝贵财富",任何事先找积极面
- **病根**: 训练出的"有益助手"人设
- **修法**: 允许负面结论存在。搞砸了就是搞砸了,没必要升华。

### §10 自问自答式推进
- **症状**: "什么是X?X是……""为什么?因为……"连续出现
- **病根**: 修辞手法被高频复用
- **修法**: 最多保留一处,其余改成直接陈述或叙述推进。

### §11 万能金句 / 鸡汤公式
- **症状**: "不是X,而是Y""真正的X,是Y""X的意义,在于Y"
- **病根**: 高质量训练数据(散文、演讲)的句式被过度采样
- **修法**: 识别出公式就重写。把判断句改回陈述句,或用具体事实替代
  抽象判断。

### §12 排比对仗堆砌
- **症状**: "既…又…还…""不是…而是…更是…"连续排比;
  对仗工整的句子成串出现
- **病根**: 中文训练数据中演讲稿、评论员文章的感染力句式被学习
- **修法**: 一段最多留一组排比,且必须承载真实信息增量。工整对仗
  拆散一处:长短错落。"文似看山不喜平"。
- **注意**: 虎嗅检测文章实测数据:AI 文本中对偶句密度约为人类写作
  的 6 倍(4次/千字 vs 0.67次/千字)。排比是最明显的 AI 指纹之一。

### §13 惊讶转折滥用
- **症状**: "有趣的是""值得注意的是""更令人惊讶的是""鲜为人知的是"
- **病根**: 吸引注意力的训练倾向
- **修法**: 全文最多一处。其余直接说事,信息本身是否惊人让读者自己判断。

### §14 数字造假 / 精确化幻觉
- **症状**: "超过 80% 的用户""研究表明效率提升 37%"
- **病根**: 模型倾向于给出看起来精确的数字
- **修法**: 有来源就引来源,没来源就用"多数""不少""大约"或删掉数字。

## 二、语言层面的模式

### §15 AI 高频词
- **症状**: "然而""此外""值得注意的是""总而言之""不可或缺"
  "至关重要""旨在""赋能""助力""深度融合""极大地""显著提升"
- **病根**: 训练数据的高频词分布与人类偏好语料的重合
- **修法**: 见高频词替换表。但要配合句式改写,单纯换词无效。
- **参考替换表**(不是死的,按语境挑):
  - 然而 → 不过 / 但 / 可(口语感) / 直接删掉靠语序转折
  - 此外 → 另外 / 还有 / 直接开新段
  - 值得注意的是 → (删) / 有意思的是(限一次)
  - 总而言之 → 说到底 / 归根结底(少用)
  - 不可或缺 → 少不了 / 必须有
  - 至关重要 → 太关键了 / 天大的事(按语境)
  - 旨在 → 是为了 / 想要
  - 赋能 → 帮着做到 / 删
  - 显著提升 → 明显好了 / 提升不少

### §16 讲义腔 / 路标词
- **症状**: "首先…其次…再次…最后…""让我们来看…""接下来我们将…"
  "如前所述""正如我们所见"
- **病根**: 教学语料和结构化输出的惯性
- **修法**: 删掉路标,让内容自然流动。逻辑关系靠内容本身呈现,
  不靠路标词宣布。

### §17 "不是X,而是Y"二分句式
- **症状**: "这不仅是技术问题,更是管理问题""关键不是X,而是Y"
- **病根**: 强调句式的高频复用
- **修法**: 保留全文最关键一处,其余重写。二分法本身是偷懒的分析。
- **检测数据**: 单篇出现 3 次以上,几乎必为 AI 或重度 AI 辅助。

### §18 同义词轮换回避
- **症状**: 同一个概念换着词叫:"这个方法""该策略""这一手段"
  "此方案"轮着用,刻意回避重复
- **病根**: 多样性奖励的训练倾向
- **修法**: 人类写作核心词就是反复用。统一回一个最准确的词。
  术语的一致性 > 措辞多样性。

### §19 欧化翻译腔
- **症状**: "被"字句滥用;"作为一个…,…"开头;"当…的时候"高频;
  定语从句层层套叠("这是一个关于…的…的…的故事")
- **病根**: 训练数据中翻译语料占比高,英文句式直译
- **修法**: "被"字句改主动;"作为"开头改为直接身份陈述;
  长定语拆成短句;"当…的时候"多数可直接删"当"和"的时候"。

### §20 模板段落与均匀节奏
- **症状**: 每段都是"主题句+2-3个支撑句+小结句"的标准结构;
  段落长度接近;节奏可预测
- **病根**: 结构化训练数据(作文、报告)
- **修法**: 打乱段落模式:一段只有一句话;一段跑题再拉回;
  一段先例子后观点(倒装段落)。段落长短错落。
- **burstiness 检测**: AI 检测器实测 burstiness 指标:AI 文本普遍
  在 0.3-0.5,人类写作 0.6-0.9。句长方差是最硬的统计指纹,
  逐词替换改变不了它。

### §21 引经据典模板
- **症状**: "正如鲁迅所说""古人云"引用鲁迅、爱迪生、爱因斯坦等
  高频名人的套话名言
- **病根**: 训练数据中名言被过度关联到主题
- **修法**: 换冷门但准确的引文,或删掉用自己的话说。

### §22 名词化倾向
- **症状**: 动词都变成名词:"进行分析"而不是"分析",
  "实现优化"而不是"优化","予以考虑"而不是"考虑"
- **病根**: 正式文书语料的惯性
- **修法**: 名词短语还原为动词。"对X进行Y"→"Y了X"。

### §23 人造金句与断句造势
- **症状**: 把普通判断包装成金句:短句独立成段、前后留白、
  用冒号或破折号引出;连续用句号切断制造节奏感("很好。非常好。
  但没有用。")
- **病根**: 新媒体文案训练数据的"金句方法论"
- **修法**: 金句放回段落里,拆掉造势结构。判断本身没变,包装变了。
  独立成段的短句,连续出现两处以上必改。
- **关联**: 本条与 §12 排比、§20 均匀节奏合称"节奏三件套",
  是当前检测器权重最高的特征组。

### §24 引号强调癖
- **症状**: 普通词加引号表示所谓的强调或反讽:"所谓的"专家""
  "提升""效率"
- **病根**: 训练数据中引号的强调用法被泛化
- **修法**: 去掉引号,让词语本身工作。真反讽时才用,且配合上下文。

## 三、结构与节奏模式

### §25 结构三段式强迫症
- **症状**: 引言-主体-结论,主体必然三点式,开头预告结尾总结
- **病根**: 训练数据作文范文的强结构
- **修法**: 结构服从内容:两点就两点,四点就四点;结论可以是没有
  结论("这问题没答案,但可以这么看")。

### §26 过渡句冗余
- **症状**: 每段之间都有"接下来""那么""既然如此"类过渡
- **病根**: 结构化写作训练
- **修法**: 删掉多数过渡句。人类写作靠内容逻辑衔接,段落间跳跃
  是常态。

### §27 段首总结强迫
- **症状**: 每段第一句都是上一段的总结或重述
- **病根**: "清晰性"奖励训练
- **修法**: 直接推进新内容。总结欲强时,问自己:这个总结删了,
  读者真的跟不上吗?

### §28 列表化倾向
- **症状**: 动不动列 1234,大量使用冒号列举
- **病根**: 格式化输出的训练惯性
- **修法**: 散文化叙述。真正需要清单时才用列表(如本文)。

## 四、标点与格式模式

### §29 破折号滥用
- **症状**: "——"插入语频率极高;一个句子里 2 个以上破折号
- **病根**: 长句训练数据的标点分布
- **修法**: 一段最多一个破折号。插入语改用逗号或括号,
  或拆成新句。

### §30 分号排列癖
- **症状**: 长句内大量分号并列,结构完全对称
- **病根**: 结构化表达惯性
- **修法**: 拆句。分号保留给真正的并列复杂项。

### §31 省略号与感叹号
- **症状**: "……"表示深思或留白,"!!""?!"高频
- **病根**: 情感增强训练
- **修法**: 省略号每千字最多一处;感叹号千字最多一处;
  "??"改为具体疑问。

### §32 格式装饰强迫
- **症状**: 大量加粗、emoji、分隔线;标题层级过深
- **病根**: Markdown 渲染奖励
- **修法**: 删。强调靠句子的位置和力度,不靠加粗。

## 五、对话与交流残留模式

### §33 对话残留
- **症状**: "您""我们可以一起""您是否考虑过""希望对您有所帮助"
- **病根**: 对话训练上下文泄漏到文本
- **修法**: 全部删除。文本就是文本,不是对话。

### §34 谄媚与自我指涉
- **症状**: "这是一个很好的问题""我很高兴为您…"
  "作为AI语言模型"(或变体如"作为一个助手")
- **病根**: 对话人设训练
- **修法**: 删除。改写时不需要解释自己在改写,直接给出结果。

## 六、模型指纹参考

不同模型有不同偏好,改写时可针对性检查(不必逐条报出):
- DeepSeek R1: 高频"嗯""好""所以"开场词;思维链泄漏;小标题加"#"号
- GPT 系列: 高频"delve""tapestry"直译腔;三点式;总-分-总
- Claude: "It's important to note"直译;平衡表述;however高频
- 文心: 四字格堆砌;成语密度高;"随着…的发展"
- Kimi: 长难句;多重从句;"值得注意的是"
- 豆包: 口语化过度;语气词密集
- 通义: 排比;对仗;"旨在""助力"
- 各家通用: 高频转折词+均匀节奏+安全表述,见上文各节

## 七、检测与验证(改写后自查)

1. **朗读测试**: 出声读一遍。哪里读着顺但记不住,哪里就有问题。
2. **抽样检查**: 随机选三段,检查:
   - 句长是否有明显起伏( longest sentence / shortest > 4x)
   - 是否存在连续两个结构相同的句子
   - 是否有"可删而意思不变"的句子(有=删)
3. **不要误伤**: 不要把人类写作的正常特征当 AI 味清除:
   - 真实的口语化表达、地方方言
   - 领域内必要的术语
   - 作者有意的修辞选择(如刻意的排比)
   - 人类也会用"然而""此外",偶用不是指纹
4. **防过度纠偏**: 不要为了去 AI 味把文本改得诡异或错误:
   - 不编造事实、数据、引文(改写只改形式,不改内容)
   - 不改变原文的核心观点和立场
   - 语法正确性、信息准确性优先于"像人"
   - 紧张、动作段落本就该短句密集,别为拉句长指标硬塞长句
5. **虚构类文本例外**: 编细节本来就是小说的活,§6"万能例子"
   对小说无效。小说主要盯:§11-12 金句/排比、§20 节奏均匀、
   §23 断句造势、§29-31 标点。

## 八、使用方式

### 粘贴文本模式
用户粘贴文本+说"去AI味"/"humanize"/"改得像人写的",执行本技能。

### 文件模式
用户说"帮我把 path/to/file.md 去AI味",读取文件,改写,写回。

### 嵌入模式(其他技能可引用)
写作类技能在最后加一步"humanize 检查",引用本技能清单做终审。
