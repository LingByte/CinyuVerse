# AI 面板使用指南

## 概述

`Ctrl+L` 打开的 AI 抽屉使用 **UnifiedAiPanel**，包含两套能力：

1. **本地对话·创作** — Rust + 本地工作区（多轮对话持久化 + 三层创作流水线）
2. **后端对话·创作** — Go Story API（智能体对话 + 写下一章/审核/润色等）

独立 detach 子窗口（视图 → 拆出 AI 面板）仍只显示后端 `AiChatPanel`。

## 本地：对话与创作

选 **本地对话·创作** 后切换 **对话** / **创作**；**+** 新建会话，Sparkles 提取文风。

## 后端：对话与创作

选 **后端对话·创作**（需 Go 服务与书籍）后切换 **对话** / **创作**。

## 打开 / 关闭

| 操作 | 方式 |
|------|------|
| 打开 | `Ctrl+L`（Mac：`Cmd+L`） |
| 关闭 | 再次 `Ctrl+L`，或抽屉标题栏关闭 |
| 关闭 | `Esc`（AI 面板打开时） |
| 菜单 | 视图 → 切换 AI 助手 |

## 两种模式

### 简易单模型

- 顶栏选择「简易」
- 适合续写、问答、单轮改写
- 自动注入工作区设定、大纲、当前章节路径上下文

### 三层流水线

- 顶栏选择「三层流水线」
- 依次执行：**大纲要点 → 正文撰写 → 校对润色**
- 各阶段结果在对话区以阶段卡片展示
- 若当前打开的是本地章节文件，最终结果可自动写回该文件

输入写作指导（可选）后发送即可开始。

## 锁定上下文

面板中部「锁定上下文片段」：

1. 粘贴关键设定、人设、伏笔等
2. 点击「固定」
3. 后续截断章节正文时会**优先保留**已锁定片段，再截取正文尾部

适合长篇连载时固定核心设定。

## 提取文风样本

顶栏 Sparkles 按钮：从现有章节采样文风，写入 `.cinyuverse/project.json` 的 `style_sample` 字段，供后续 prompt 使用。

也可在 ActivityBar **任务** 面板创建「提取文风样本」异步任务。

## 界面结构

```
┌─────────────────────────────┐
│ [简易] [三层流水线]  Sparkles│
├─────────────────────────────┤
│ 锁定上下文片段               │
├─────────────────────────────┤
│  消息列表 / 阶段卡片         │
├─────────────────────────────┤
│  输入框 + 发送               │
└─────────────────────────────┘
```

## Go Story 章节

从「后端」面板打开的章节使用虚拟路径 `cinyuverse://story/...`。可在后端面板底部点击 **「三层流水线处理当前章」**：

- 需同时打开**本地工作区文件夹**
- 使用本地 Rust 流水线处理编辑器中的章节内容
- 结果写回 Go 章节存储

## 与 AI 任务面板的关系

| 场景 | 使用 |
|------|------|
| 交互式单章写作 / 润色 | WorkspaceAiPanel（本面板） |
| 批量多章润色 / 生成 | ActivityBar → 任务 → 批量队列 |
| 规则剧情审校（无 LLM） | 任务 → 剧情审校 |
| 深度剧情审校 | 文件 → 剧情审校报告 |

批量任务会自动逐章调用与流水线相同的 stage prompt，无需在本面板手动重复操作。

## 前置条件

1. **打开工作区文件夹**（文件 → 打开文件夹）
2. 完成 AI 配置，见 [ai-configuration-guide.md](./ai-configuration-guide.md)
3. 发送失败时见 [ai-troubleshooting.md](./ai-troubleshooting.md)

## 主题

AI 面板颜色跟随全局主题（`themes.css`）。编辑页与其他栏位使用统一的 `--wp-panel-surface` 半透明遮罩。

更完整的功能说明见 [usage-guide.md](./usage-guide.md)。
